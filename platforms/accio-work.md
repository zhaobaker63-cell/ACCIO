# Accio Work 适配

## 状态
**已提供平台无关的核心规则；Accio Work 实际账户是否支持上传标准 SKILL.md、从 GitHub 安装或引用目录的能力尚未确认。**

## 分级接入方案
1. 支持标准 Skill 导入时：优先导入 `.agents/skills/demo-solution-architect/` 并保留完整目录结构。
2. 仅支持自定义 Skill 文本：将 `SKILL.md` 的核心步骤和默认输出规则写入平台 Skill 配置；将 references 模板以平台支持的文件资源方式提供。
3. 仅支持 Agent 指令：以“Demo 技术架构老师”角色配置同等规则，必要时明确要求逐次读取外部模板；不能把它称为已安装标准 Skill。

## 验证任务
输入：`评估企业产品RAG、传统关键词检索和结构化数据库查询三种实现方法，说明何种场景不必用RAG，并生成学习卡草稿。`
观察：是否遵守先选型后开发；是否真实读取模板；是否区分已验证与推断；是否在无写权限下只输出草稿。

## 留意事项
企业知识和客户数据需要有明确授权和数据隔离。不得将公司真实私有资料推送到公开 GitHub。具体 API、Skill Hub 导入、文件读写和模型能力需要以当前产品版本及实际授权验证。
