# 腾讯 WorkBuddy 适配

## 状态
**通用 Skill 指令与 Markdown 文件准备完成；具体 WorkBuddy 版本的原生目录发现、GitHub 安装、压缩包导入行为尚未实机验证。**

## 优先适配路径
1. 如果当前 WorkBuddy 支持导入标准 Skill 目录：导入 `.agents/skills/demo-solution-architect/` 文件夹，保留全部 references/examples 子目录。
2. 如果仅支持上传一个 Skill 主文件：导入本目录中的 `SKILL.md`，再按平台允许的方式添加 references 文件；若不支持补充文件，则将所需模板粘入配置上下文。
3. 如果只有自定义 Agent 指令能力：将 `SKILL.md` 的主体设置为自定义指令，明确“参照本地 templates 输出草稿”；不得宣称具备自动读写知识库的能力。

## 验证
- 触发双模式，比较至少两条真实可行路线；额外引出未知IT知识并清楚解释原理。
- 检查能否调用文件读取、检索和写入功能，以及是否获得用户授权。
- 同一 Demo 再次询问时，看是否真实读取了先前持久化文件；不能仅凭聊天记忆断言跨会话永久保存。

## 限制
WorkBuddy 的功能与安装规则可能因版本和账号改变；无公开证据时只标注“待确认”。不建议为了本 Skill 引入大量自动点击操作或额外付费服务。
