# 四平台兼容性跟踪

| 平台 | 核心Markdown可迁移 | 标准SKILL.md目录 | 原生导入已实测 | 知识文件持久化已实测 | 说明 |
|---|---|---|---|---|---|
| Codex | 是 | 适配目录已提供 | 否 | 否 | 使用 .agents/skills 标准布局；目标环境需测试 |
| WorkBuddy | 是 | 待按平台版本核验 | 否 | 否 | 可能需要 Skill 文本/Agent 指令适配 |
| Accio Work | 是 | 待按账户能力核验 | 否 | 否 | 平台特性、文件导入和写权限待核验 |
| DeepSeek Harness | 是 | 按具体发行版适配 | 否 | 否 | 需确认 Harness 的 Skills 发现与工具许可 |

“核心 Markdown 可迁移”仅指指令可以转写/导入，不等于一键安装、原生自动触发、联网工具调用或长期记忆自动工作。

## 最小回归清单
- [ ] 可以触发 Skill（非普通聊天回复）
- [ ] 能读取多文件模板，或明确采用内联替代
- [ ] 能输出可行的多技术路线和首选/备选
- [ ] 主动解释2—4个项目相关新IT概念
- [ ] 默认不写代码、不改动外部系统
- [ ] 验证信息附来源、时间、版本或待验证标识
- [ ] 有写权限时可持久化知识卡，无权限时不谎称保存
- [ ] 先前知识能在新的项目再次引用并更新

每次实测写明平台版本、日期、安装方式、输入指令、证据与失败原因。不得仅以文件已上传GitHub判定测试通过。
